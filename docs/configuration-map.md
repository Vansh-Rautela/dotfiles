# Configuration map

Every file in this repo, what it changes, and whether it replaces or extends
an Omarchy-managed file. "Deploy" is how `bootstrap/install.sh` puts it in
place.

| Path in repo | Deploys to | Relationship to Omarchy | What it actually changes |
|---|---|---|---|
| `nvim/` | `~/.config/nvim` (symlink) | Not Omarchy-managed -- Neovim config is fully user-owned space | LazyVim base + custom: `cpp_dsa.lua`/`cpp-dsa.lua` (competitive programming), `leetcode.lua`, `jest.lua`, `jupyter.lua`, `telescope.lua`, `all-themes.lua`, `omarchy-theme-hotreload.lua` (syncs nvim colorscheme to Omarchy's active theme), `remote_clipboard.lua`, `lualine-transparent.lua`, custom keymaps/autocmds/options |
| `hypr/bindings.lua` | `~/.config/hypr/bindings.lua` (symlink) | Extends Omarchy's template (26-line diff, mostly stale comment wording from an older Omarchy release) | Adds one real binding: `SUPER + A` -> Exposé window overview |
| `hypr/looknfeel.lua` | `~/.config/hypr/looknfeel.lua` (symlink) | Extends Omarchy's template | Sets `gaps_in=1, gaps_out=1, border_size=1, layout="scrolling"` (niri-style scrolling layout) -- the template ships these commented out at 0/0/0 |
| `hypr/monitors.lua` | `~/.config/hypr/monitors.lua` (symlink) | Replaces Omarchy's generic auto-detect template | **Machine-specific.** Laptop `eDP-1` at `0x0` `1920x1080@120`, external `HDMI-A-1` at `1920x0` `1600x900@60`, both scale 1, `GDK_SCALE=1`. OpenTabletDriver's display mapping assumes this exact layout. |
| `terminal/alacritty/alacritty.toml` | `~/.config/alacritty/alacritty.toml` (symlink) | **Replaces** Omarchy's default, which is just `general.import = [".../theme/alacritty.toml"]` | Opts OUT of Omarchy's dynamic theme switching entirely; hardcodes a static dark palette, opacity 0.55, no decorations, font size 7 |
| `terminal/ghostty/config` | `~/.config/ghostty/config` (symlink) | Extends Omarchy's template (keeps the dynamic `config-file = .../theme/ghostty.conf` include) | font-size 9->7, 2 extra unbound keys, custom scroll multiplier, `async-backend=epoll` workaround |
| `terminal/foot/foot.ini` | `~/.config/foot/foot.ini` (symlink) | Extends Omarchy's template (keeps the dynamic theme `include=`) | font-size 9->7 |
| `terminal/kitty/kitty.conf` | `~/.config/kitty/kitty.conf` (symlink) | Replaces the commented teaching-scaffold body of Omarchy's template, keeps its theme include | Custom font/window/keybindings/tab-bar styling |
| `terminal/tmux/tmux.conf` | `~/.config/tmux/tmux.conf` (symlink) | **Replaces** Omarchy's default tmux keybinding scheme wholesale | Entirely different pane/window/session keybindings from Omarchy's defaults -- too extensively restructured to express as a small delta, see README for why this one is a full replacement |
| `git/personal.gitconfig` | Merged via `[include]` added to `~/.config/git/config` | Extends -- Omarchy's own aliases/pull/push/diff/rerere defaults in that file are untouched | `[user]` name/email, GitHub/Gist credential helpers via `gh` |
| `gtk/gtk-3.0/settings.ini` | `~/.config/gtk-3.0/settings.ini` (symlink) | Personal (not Omarchy-managed) | Theme=WhiteSur-Light, icons=WhiteSur-light, font="SF Pro weight=860 11", cursor=default |
| `gtk/gtk-3.0/gtk.css` | `~/.config/gtk-3.0/gtk.css` (symlink) | Personal, generated by a separate tool (see below) | GTK3 global override CSS: sharp corners (`border-radius: 0`), a catppuccin-ish palette. Sourced from `~/.config/aether` (a separate theme-generation app, not otherwise captured -- see `packages/notes.md`) |
| `gtk/gtk-4.0/settings.ini` | `~/.config/gtk-4.0/settings.ini` (symlink) | Personal | Same theme/icon/font selection as gtk-3.0 |
| `gtk/gtkrc-2.0` | `~/.gtkrc-2.0` (symlink) | Personal (managed by `nwg-look`) | Legacy GTK2 theme/font/cursor settings |
| `opentabletdriver/settings.json` | `~/.config/OpenTabletDriver/settings.json` (symlink) | Personal | Huion HS64 profile: tablet area, **machine-specific display mapping to HDMI-A-1**, pen/aux button bindings (Ctrl+Z, H, Keypad0/2/7) |
| `opentabletdriver/plugins/Precision Control/metadata.json` | Not deployed (reference only) | Personal | Metadata + download URL for a third-party OTD filter plugin that was installed but **disabled** on the source machine |
| `firefox/chrome/` | Copied (not symlinked) into the active profile's `chrome/` dir | Personal | `userChrome.css`, `userContent.css`, `customChrome.css`, WhiteSur Firefox theme assets |
| `firefox/user.js` | Copied into the active profile root | Personal | Enables legacy stylesheet customizations, titlebar drawing, uidensity, GPU/ARGB/rounded-corner tweaks |
| `packages/pacman.txt`, `packages/aur.txt` | Installed via `pacman -S` / AUR helper | N/A | Packages beyond a stock Omarchy install -- see `packages/notes.md` for how this was derived and what was deliberately excluded |
| `Wallpaper/` | Not deployed by install.sh | Pre-existing in this repo (predates this audit) | Personal wallpaper images; not wired into Omarchy's background rotation -- left as-is |

## Deliberately NOT included (audited and found to be unmodified or inactive)

- `hypr/autostart.lua`, `hypr/hyprland.lua`, `hypr/xdph.conf` -- byte-identical to Omarchy's templates
- `hypr/input.lua`, `hypr/hyprsunset.conf` -- differ from the template only inside comments; zero functional change
- `hypr/envs.conf`, `hypr/hypridle.conf`, `hypr/hyprlock.conf`, `hypr/hyprmodoro.conf` -- present on disk but not `require`d/sourced by anything active; `hypridle`/`hyprlock` processes aren't running, idle/lock is handled by `omarchy-sleep-lock.service` instead. Left in place on the source machine, not captured here.
- `~/.config/btop/btop.conf`, `~/.config/starship.toml` -- byte-identical to Omarchy's templates
- `~/.config/gtk-4.0/gtk.css`, `gtk-dark.css` -- symlinks into the installed WhiteSur-Light theme package, not personal files
- `~/.config/gtk-4.0/gtk-Light.css`, `gtk-Dark.css` -- ~9,250-line generated theme stylesheets, regenerated by the WhiteSur theme installer
- `~/.config/fish` -- fish is installed but isn't `$SHELL`; its config is fish's own stub plus an auto-inserted LM Studio PATH export, no real customization
